# Business Sales Intelligence Dashboard

## About the Project
The Business Sales Intelligence Dashboard is a Python-based project that analyzes sales data and displays useful business insights through interactive charts and metrics.

## Features
- Region-wise sales filtering
- Total sales calculation
- Total profit calculation
- Monthly sales trend
- Category-wise sales visualization
- Region-wise sales visualization
- Top-selling product analysis

## Technologies Used
- Python
- Pandas
- Streamlit

## Project Files
- `app.py` – Main dashboard application
- `analysis.py` – Sales analysis script
- `sale_data.csv` – Sales dataset
- `ecommerce_customer_behavior_dataset.csv` – Customer behavior dataset
- `requirements.txt` – Required Python libraries

## How to Run the Project

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run app.py
```
